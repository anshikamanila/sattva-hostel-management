# SATTVA Attendance MVP — Phase 1

Frontend foundation and Warden dashboard for the SATTVA Attendance MVP.

## Run locally

```bash
npm run dev
```

The development server runs on port `5000` and is configured for Replit's
proxied preview.

## Current phase

This phase intentionally uses realistic mock attendance data only. It includes
the Warden application shell, overview dashboard, attendance register,
student directory, missing/submitted views, attendance trend, and quiet
operational status.

Supabase, authentication, backend services, database persistence, AI,
notifications, IoT, and future hostel modules are not included yet.
